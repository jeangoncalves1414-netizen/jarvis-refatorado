# Visão Geral do Projeto

## Objetivo do projeto
Este projeto é uma reconstrução de uma assistente pessoal autônoma para Windows, com foco em:
- interação por voz e texto,
- visão computacional da tela,
- memória persistente e contexto,
- automação de desktop,
- painel modular e extensível.

## Objetivo principal
Criar um agente capaz de:
- entender a intenção do usuário,
- tomar decisões próprias com base em preferências e contexto,
- executar ações de forma segura,
- aprender com o comportamento do usuário,
- oferecer um painel leve, moderno e modular.

## Princípios da reconstrução
- modularização forte,
- separação de responsabilidades,
- baixo acoplamento,
- fácil manutenção,
- arquitetura preparada para evolução,
- UI leve e independente de arquivos gigantescos.

## Escopo inicial
O escopo inicial deve priorizar:
1. agente conversacional,
2. painel essencial,
3. memória persistente,
4. visão computacional básica,
5. ferramentas de automação simples,
6. comandos e fluxos de execução bem documentados.

## Não escopo inicial
- recursos excessivamente avançados,
- múltiplos painéis complexos,
- integrações desnecessárias,
- lógica espalhada em arquivos monolíticos.
